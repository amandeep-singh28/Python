Django Admin & Superuser – Short Notes

1. migrate:
Command: python manage.py migrate
- Creates database tables.
- Required for authentication and admin system.

2. createsuperuser:
Command: python manage.py createsuperuser
- Creates an admin account with full permissions.
- Allows access to the admin panel.

3. runserver:
Command: python manage.py runserver
- Starts the development server.

4. Admin Panel:
URL: http://127.0.0.1:8000/admin/
- Login using superuser credentials.
- Manage users and models (Add, Edit, Delete).

Django Admin is a built-in powerful tool that provides automatic CRUD operations and user management without writing extra frontend code.

->Users and groups

Django Users and Groups – Short Notes

1. Users:
- Represents individual accounts.
- Stores username, password (hashed), email, etc.
- Types:
  • Normal User – No admin access.
  • Staff User – Can access admin panel (limited permissions).
  • Superuser – Has all permissions.

2. Groups:
- Collection of users.
- Used to assign permissions to multiple users at once.
- Helps implement Role-Based Access Control (RBAC).

Example:
Instead of giving permissions to each user individually,
create a group (e.g., Editor, Manager) and assign permissions
to the group, then add users to that group.

Django uses:
- User model
- Group model
- Permission model

->Linking a table(app) with superuser
Create a model in models.py(app)
    from django.db import models

# Create your models here.
class Student(models.Model):

    Branch_choices = [
        ('CS', 'Computer Science'),
        ('ELEC', 'Electronics'),
        ('CIVIL', 'Civil Engineering')
    ]

    name = models.CharField(max_length = 100)
    email = models.EmailField()
    age = models.IntegerField()
    branch = models.CharField(max_length = 20, choices = Branch_choices)

    def __str__(self):
        return self.name

In admin.py
    from django.contrib import admin
    from .models import Student
    # Register your models here.

    @admin.register(Student)
    class StudentAdmin(admin.ModelAdmin):
        list_display = ('name', 'email', 'age', 'branch')

->How to upload image
(i)In your project settings.py, at the end write this code
import os
MEDIA_URL = '/media/'
MEDIA_ROOT = os.path.join(BASE_DIR, 'media')

(ii)In your app models.py add this code (Whatever image will be uploaded, it will get stored in that folder)
image = models.ImageField(upload_to = 'students/', null = True, blank = True)

->Now how to see the image on html
Add this code in your app urls.py

from django.conf import settings
from django.conf.urls.static import static

if settings.DEBUG:
    urlpatterns += static(settings.MEDIA_URL, document_root=settings.MEDIA_ROOT)

->app views.py
from django.shortcuts import render
from .models import Student

def show_students(request):
    students = Student.objects.all()
    return render(request, "form.html", {"students": students})

->app urls.py
from django.urls import path
from . import views
from django.conf import settings
from django.conf.urls.static import static
