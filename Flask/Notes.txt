from flask import Flask, redirect , url_for, session, Response, request

app = Flask(__name__) # This intializes our application
app.secret_key = 'supersecretkey'

@app.route('/', methods = ['POST', 'GET'])

def login():
    if request.method == 'POST':
        username = request.form.get('username')
        password = request.form.get('password')
        if username == 'amandeep' and password == '123':
            session['user'] = username
            return redirect(url_for('welcome'))
        else:
            return Response('Invalid credentials ', 401)
        
    return '''
        <h2> Login page </h2>
        <form method = "post">
            Username: <input type = "text" name = "username"><br>
            Password: <input type = "password" name = "password"><br>
            <input type = "submit" value = "Login">
        </form>
    '''

@app.route('/welcome')
def welcome():
    if 'user' in session:
        return f'''
        <h2>Welcome, {session["user"]}!</h2>
        <a href = {url_for('logout')}>Logout</a>
        '''
    return redirect(url_for('login'))

@app.route('/logout')
def logout():
    session.pop('user', None)
    return redirect(url_for('login'))

****Flask Sessions****
Flask session remembers a user across multiple web pages.
->Used for login/logout
->Stores user-related data (like user id, username)
->One session per user (per browser)
->Helps the website know who is logged in

*****SQLALCHEMY Sessions****
SQLAlchemy session manages database operations for objects.
->Used to insert, update, delete data
->Tracks database changes before saving
->Not related to web pages or users directly
->Works per database transaction, not per website user

->Function of ORM(Object Relational Mapper)
It maps the databases table to other programming languages such as Python so that the developer can interact with the database using object oriented programming instead of SQL.

1. What is db.create_all()?

- It creates all tables defined in your models.
- If a table does NOT exist → it creates it.
- If a table already exists → it does nothing.
- It does NOT modify existing tables.
- It does NOT delete columns.
- It does NOT update schema.

2. Do we need to write db.create_all() every time?

NO.
You only need ONE db.create_all() in your project.

Example:

with app.app_context():
    db.create_all()

After that:
- If you add a new model, just run the app again.
- It will automatically create only the new table.

3. Important Rule

Every model must have at least one primary key.

Example:

class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(200))

Without primary key → SQLAlchemy will give an error.

4. Limitation

If you change an existing table (add/remove columns),
db.create_all() will NOT update it.

For schema changes, use Flask-Migrate.
